# STALKER all.spawn utils
Утилита для работы с файлом `all.spawn` из `ТЧ` `1.0006`. На других файлах утилита не тестировалась.

## Использование
Утилита запускается с помощью файла `spawn.py`.
Путь к `all.spawn` файлу указывается в файле `spawn.py`, в глобальной переменной `file_path`.
Скрипт написан на `python`, поэтому для запуска нужно установить интерпретатор `python`.

## Функционал
На текущий момент есть возможность только печати информации из файла в консоль. Если таким способом перенаправить вывод, то можно получить `*.ltx` файл с параметрами из `all.spawn` файла:

`spawn.py > all_spawn.ltx`

## Ограничения
Не печатается информация из `Update NET`-пакетов.
